Python for Digital Humanities

🎓
Why Python in Digital Humanities?

Humanities research has always been about texts, archives, images, and patterns in human culture. Python lets you work with these at scale — reading thousands of documents, finding patterns across corpora, and visualising language — things impossible by hand alone.

📖

Text Analysis at Scale

Literature, history, journalism — Python can read entire archives in seconds, counting words, tracking themes, and finding patterns that would take human readers years.

🗺️

Corpus Linguistics

Linguists use loops and string operations to study how language changes over time — which words appear together, how sentences are structured across dialects and eras.

🏛️

Archive Processing

Historians process digitised newspapers, letters, and records. Variables store data; loops process thousands of documents; conditions filter relevant entries.

🎨

Visual Storytelling

Word clouds turn raw text into visual arguments — a tool for communicating findings to non-technical audiences, used in journalism, public history, and education.

🔍

Critical Search

Filtering with conditions (if/else) mirrors archival source criticism: not all data is relevant. Code makes selection criteria explicit and reproducible.

🤝

Open & Reproducible

Python is free, widely taught, and runs in a browser via Colab. Sharing a notebook means sharing the method — making humanities research as transparent as a footnote.

Session 01 — The building blocks

These exercises cover the core ideas all programming is built on: arithmetic, variables, loops, conditions, and string operations. In Digital Humanities, these become tools for working with words, sentences, and collections of texts.

Arithmetic & Variables

ArithmeticEx 01

Python as a calculator. The result appears immediately — good for testing ideas quickly.

3 + 2
  • + – * / // % ** — basic operators
  • // integer division  ·  % remainder  ·  ** power
Counting word frequencies, page numbers, years between dates
Variables & StringsEx 02

A variable stores a value and gives it a name. Strings are text wrapped in quotes. + joins strings together.

first_name = "Juku"
print("Hello, " + first_name)
  • = assigns a value to a name
  • print() displays the result
  • Strings use " " or ' ' quotes
Storing an author's name, a book title, a date, a source URL

Loops

Loop over numbersEx 03

range(5) produces 0, 1, 2, 3, 4. The loop runs the indented block once per value.

for number in range(5):
    print(number)
  • for … in …: — the loop structure
  • range(n) — integers from 0 to n–1
  • Indentation (4 spaces) marks the loop body
Numbering pages, iterating over years, processing rows in a dataset
Loop over charactersEx 04

You can loop over any sequence — including the letters in a string, one at a time.

for letter in first_name:
    print(letter)
  • A string is a sequence of characters
  • Same for … in … pattern as Ex 03
Reading a text character by character — useful for encoding detection, transliteration

Conditions

if / elseEx 05

Make a decision based on a condition. If the condition is true, run the first block; otherwise, run the else block.

age = 8
if age <= 7:
    print("Free")
else:
    print("Buy a ticket")
  • <= >= == != < > — comparison operators
  • == checks equality (not = which assigns)
Filtering sources by date, selecting texts from a certain period
Nested if / elseEx 06

Conditions can nest inside each other, creating multiple decision paths.

age = 8
if age <= 7:
    print("Free")
else:
    print("Buy")
    if age <= 18:
        print("child ticket")
    else:
        print("full ticket")
  • Each level of nesting adds 4 more spaces
  • Use elif to chain conditions cleanly
Classifying texts by era, genre, or word count across multiple categories

String Slicing

Slicing a stringEx 07

Extract any part of a string using [start:end:step]. Indices start at 0; negative indices count from the end.

sentence = "racecarleveldeified"

print(sentence[0:3])    # "rac"
print(sentence[:3])     # "rac"  (start defaults to 0)
print(sentence[5:10])   # characters 5–9
print(sentence[5:])     # from index 5 to end
print(sentence[-1])     # last character
print(sentence[-4:])    # last 4 characters
print(sentence[5:][0])  # chain slices
print(sentence[::2])    # every 2nd character
  • [start:end] — end is not included
  • [-1] — last character; [-n:] — last n characters
  • [::2] — every other character (step)
Extracting date components, file name prefixes, citation codes from structured text
Splitting into wordsEx 08

.split() breaks a string into a list of words. Lists can be sliced just like strings.

sentence = "Alice went to the park..."
words = sentence.split(" ")

print(words)         # full list
print(words[0])      # first word
print(words[0:3])    # first 3 words
print(words[-3:])    # last 3 words
print(len(words))    # word count
print(words[2][0])   # 1st letter of 3rd word
print(words[-1][-1]) # last letter of last word
  • .split(" ") splits on spaces → list of words
  • len() counts items in a list
  • Chain: words[i][j] — j-th character of i-th word
Tokenising sentences, counting words in a passage, finding the first word of each sentence

List Comprehensions

Basic list comprehensionEx 09

A compact way to loop over a list and collect results. This one just reproduces the words, but sets up the pattern.

sentence = "When Alice and her younger..."
words = sentence.split(" ")

print([word for word in words])
  • Structure: [expression for item in list]
  • Returns a new list
The foundation of text processing — every word in a corpus becomes a data point
Comprehensions with transforms & filtersEx 10

List comprehensions can transform each item and optionally filter with if. Very powerful for text analysis.

# First letter of every word
[word[0] for word in words]

# Length of every word
[len(word) for word in words]

# Only short words (5 letters or fewer)
[word for word in words if len(word) <= 5]

# First+last letter of long words
[word[0] + word[-1] for word in words
 if len(word) >= 5]

# Join result with underscores
"_".join([word[0]+word[-1]
          for word in words if len(word)>=5])

# Reverse the word list
words[::-1]
  • Add if condition at the end to filter
  • "sep".join(list) — joins list into one string
  • [::-1] — reverses any sequence
Extract initials, find long words, build concordances, reverse a sentence for analysis

Session 02 — Word clouds & text visualisation

These exercises load real text from the web, generate word clouds, apply image masks, filter stopwords, and customise colours — turning a plain text file into a visual argument about its content.

Setup & Basic Word Cloud

Install & first word cloudEx 11

Install the library once per session (Colab), then generate a word cloud from a string of text and display it as an image.

pip install wordcloud
from wordcloud import WordCloud

wc = WordCloud().generate("rain rain brings hope hope")
img = wc.to_image()
img.show()
  • pip install — downloads a library (once per session)
  • from … import … — brings in just the class you need
  • .generate(text) — builds the cloud from a string
  • .to_image() — converts to a viewable image
First step toward visualising any text corpus — speeches, novels, newspaper archives
Load text from the webEx 12

Fetch any public text file directly from a URL. Project Gutenberg, government archives, and digitised newspapers are all accessible this way.

import urllib.request

text = urllib.request.urlopen(
    "URL of your online text file"
).read().decode("utf-8")

text[:50]   # preview first 50 characters
  • urllib.request — built-in Python web fetching
  • .read() downloads as bytes; .decode("utf-8") converts to text
  • text[:50] — preview without printing everything
Load historical texts, digitised books, or any corpus hosted online without downloading files
Word cloud from loaded textEx 13

Once text is loaded, generating the cloud is a single chained line.

WordCloud().generate_from_text(text).to_image()
  • .generate_from_text() — takes a full text string
  • Method chaining: each . calls the next step on the result
Instant visual summary of any document — good for exploring unfamiliar corpora
Stopwords & background colourEx 14

Stopwords are common words (and, the, but…) that carry no meaning and dominate word clouds unless removed.

WordCloud(
    stopwords=["and", "then", "but"],
    background_color="white"
).generate_from_text(text).to_image()
  • stopwords= — list of words to exclude
  • background_color= — default is black
  • Use a full NLTK stopword list in Ex 17
Critical step: removing grammatical noise reveals the content words that carry meaning

Image Masks

Load an image from DriveEx 15

Download an image from Google Drive and display it. The File ID comes from the sharing link of your Drive file.

from PIL import Image
import urllib.request

img = urllib.request.urlretrieve(
    "https://drive.google.com/uc?export=download&id=FILE_ID",
    "image1.png"
)

Image.open("image1.png")
  • PIL / Pillow — Python image library
  • urlretrieve(url, filename) — downloads and saves locally
  • Replace FILE_ID with your Drive file's ID
Load historical maps, portraits, or silhouettes to use as word cloud shapes
Word cloud shaped by an imageEx 16

Use any black-and-white image as a mask — the word cloud fills the white areas of the shape.

import numpy as np

text = urllib.request.urlopen(
    "https://drive.google.com/uc?export=download&id=FILE_ID"
).read().decode("utf-8")

img = urllib.request.urlretrieve(
    "https://drive.google.com/uc?export=download&id=FILE_ID",
    "image1.png"
)

WordCloud(
    mask=np.array(Image.open("image1.png")),
    background_color="white"
).generate_from_text(text).to_image()
  • np.array(Image.open(...)) — converts image to a numeric grid
  • mask= — the shape the words must stay inside
  • Dark pixels = no words; white = fill with words
Shape a word cloud like a country outline, a book, or a person's silhouette for visual storytelling

Stopwords & Custom Colours

NLTK stopword list from webEx 17

Fetch a full professional stopword list directly from GitHub rather than typing individual words manually.

stopwords_list = urllib.request.urlopen(
    "https://gist.githubusercontent.com/sebleier/554280/..."
).read().decode("utf-8").split("\n")

WordCloud(
    mask=np.array(Image.open("image1.png")),
    background_color="white",
    stopwords=stopwords_list
).generate_from_text(text).to_image()
  • .split("\n") — splits the file into one word per line
  • NLTK stopword list: ~179 common English words
  • Can load custom stopword lists for any language
Essential for non-English corpora — load Estonian, French, or domain-specific stopwords the same way
Custom colour functionEx 18

Define your own rule for colouring words. Here: short words are green, longer ones are blue.

def color_function(word, font_size, position,
                   orientation, random_state=None,
                   **additional_args):
    if len(word) < 4:   # fewer than 4 letters
        return "green"
    return "blue"

WordCloud().generate_from_text(text)\
           .recolor(color_func=color_function)\
           .to_image()
  • def defines a reusable function
  • Colour by word length, frequency, sentiment, part of speech…
  • .recolor(color_func=) applies your function to the existing cloud
Highlight sentiment, rare vs. common words, or named entities in different colours
